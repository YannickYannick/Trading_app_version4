# Application mobile (Expo / React Native)

Client Expo pour la Trading App : authentification JWT, dashboard, courtiers, stratégies, etc., via la même API REST que le frontend web.

## Démarrage rapide

```powershell
cd mobile
npm install
npm start
```

Ouvrir le projet avec **Expo Go** ou un émulateur. Le backend Django doit tourner sur le port **8000**.
